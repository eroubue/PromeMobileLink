# 更新记录

## 0.2.6 - 2026-09-28

- 云端 ptl 采集节奏改周历：每周四窗口内排行榜一轮加模型持续推进至发布；模型片段新鲜窗放宽到 36 小时；key 耗尽轮换修复。
- Android 安装版本号提升为 `8`，云端要求 App 和插件使用 `0.2.6`。

## 0.2.5 - 2026-09-27

- Android 环境检测取号扩展为多源（订阅信息、通话记录、联系人资料、应用绑定手机号 shell 探测），并上报各来源诊断与 SIM 状态。
- 设备数据采集新增免 root 的外部存储路径（Android/data 零宽空格绕过作用域存储），与 root shell 结果按字段合并并记录来源。
- Android 安装版本号提升为 `7`，云端要求 App 和插件使用 `0.2.5`。

## 0.2.4 - 2026-09-27

- 云端 ptl 服务模型同步器增量续跑与 worker 自动推进（45 分钟冷却，先推进后排行榜）。
- Android 安装版本号提升为 `6`，云端要求 App 和插件使用 `0.2.4`。

## 0.2.3 - 2026-09-25

- 云端 ptl 服务新增战斗事件端点（样本成轴原料抓取与永久缓存）与模型同步器（节点未灌入时记失败不发布）。
- 插件 Ptl 中继扩展战斗事件查询；key 池并发记账修复。
- Android 安装版本号提升为 `5`，云端要求 App 和插件使用 `0.2.3`。

## 0.2.2 - 2026-09-24

- App 新增云端版本门禁与更新下载引导（版本不一致时提示并跳转 Releases）。
- 插件新增 Ptl 云端中继 IPC：fflogs key 上传/状态/撤下与模型清单/文件下载，供 PtlAdvisor 等模块经授权后消费。
- 云端上线 mobilelink-ptl 服务（key 池与模型分发）及样本同步常驻服务。
- Android 安装版本号提升为 `4`，云端要求 App 和插件使用 `0.2.2`。

## 0.2.1 - 2026-09-18

- 修正 CID 的十六进制显示错误，插件、App、云端和 IPC 统一使用原始十进制字符串，例如 `18014449510679448`；不限制 CID 位数或数值上限。
- 增加旧 CID 数据迁移，保留账号和角色绑定。发布时需三端同步更新，完成迁移后重启插件并重新扫码。
- Android 安装版本号提升为 `3`，云端要求 App 和插件使用 `0.2.1`。

## 0.2.0 - 2026-09-17

- App 和电脑插件使用云端要求的精确版本号，版本不一致时禁止验证与续期。
- App 更新入口指向 GitHub Releases；电脑插件通过 PR 本体的插件管理更新。
- 版本拒绝会立即清除活跃验证状态，并阻止延迟响应恢复旧授权。
- 云端授权和局域网连接票据升级为 ES256 签名，插件内置生产验证公钥。
- Android 安装版本号提升为 `2`。
- 补充开发者接入文档、设置同步示例和云端验证 IPC 示例。

更新后请同时检查电脑插件版本，并重新扫描二维码完成授权。
